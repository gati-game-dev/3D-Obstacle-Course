# 3D Obstacle Course

A beginner 3D game development project built with **Unity and C#**.

## About the Project

3D Obstacle Course is a learning project created to explore the fundamentals of 3D game development in Unity. The project involves building a simple obstacle course where the player navigates through an environment filled with obstacles, moving hazards, and traps.

The primary goal is to gain hands-on experience with 3D physics, player movement, environmental design, and collision-based gameplay while transitioning from 2D to 3D game development.

This is an ongoing learning project, with a focus on understanding core concepts and implementing them through practical experimentation.

## Learning Objectives

- Understanding Unity's 3D physics system and Rigidbody behaviour.
- Implementing physics-based player movement.
- Working with 3D collisions, triggers, and gravity.
- Exploring slopes, momentum, and jumping mechanics.
- Creating and positioning 3D environments and obstacles.
- Implementing obstacle interactions and gameplay mechanics.
- Understanding lighting, materials, and skyboxes in 3D scenes.

## Built With

- **Game Engine:** Unity
- **Programming Language:** C#
- **Physics:** Unity 3D Physics System
